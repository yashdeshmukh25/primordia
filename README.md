# Primordia

A particle universe grown from one rule: a small grid that says how strongly each colored species is pulled toward or pushed away from every other species at short range. Run that rule against a thousand particles and things nobody programmed start happening — cells, swarms, orbiting pairs, chains.

Four physics layers run at once, and none of them know about each other:

- **Local chemistry** — short-range, particle to particle.
- **Deep field** — long-range, pulling whole species toward or away from each other's center of mass.
- **Chemistry** — compatible particles bond on contact, stretch, and snap.
- **Life** (off by default) — energy, starvation, reproduction with mutation. Population becomes an outcome, not a setting.

Plus autoevolving rules, five pointer tools, a three-second rewind buffer, and a genetic seed code you can copy out and load back in later.

No build step — it's a single static `index.html`. Open it directly or serve the folder with anything that serves static files.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| Space | pause / resume |
| N | new organism |
| M | mutate local rules |
| R | reseed positions |
| U | undo local edit |
| D | toggle autoevolve |
| C | toggle chemistry |
| V | toggle life / death |
| 1–6 | pick paint species |
| `[` `]` | force down / up |
| L | jump to live |
